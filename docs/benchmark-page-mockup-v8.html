Clock and temperature ride the same sampler as RAM/VRAM peaks. A throttled repeat half is flagged and kept — a throttled run is information about sustained performance. Policy (re-run offers, steady-state discard) sits on top and is never automatic.

Discard first 1 repeat on thermally volatile machines — implemented as a scoring-side exclusion recorded in this run’s config, never post-hoc trimming outside the stored configuration. Requires repeats ≥ 4 here: discarding from 3 would leave n = 2 and break the stability gate’s n ≥ 3 floor. N6

What v8 changes on top of the v7 console

M1 Affordability inversion

“How fast” gains a sibling: “what’s the largest context that still fits?” Advisory-only, confidence-worded, feeding fit lines everywhere and ranking exactly one card.

M2 Goal questionnaire

Three questions + one collapsed. Skippable by construction; answers stored as config; re-scoring is instant post-processing, never re-measurement.

M3 Goal-parameterized cards

Fixed weights replaced by stated intent. Card membership follows the goal; Max Context ranks on estimates and says so in its own copy.

M4 Tolerance prunes the KV axis

Forbidden pairs leave the grid before expansion — counts, costs and breakdowns agree with what runs. One unquantized pair always survives.

M5 Presets carry goals

Intent about the workload travels with the grids, loaded verbatim and marked, on every machine the preset owner has.

M6 Thermal telemetry

Clock-min and temp-max columns plus a sampled series; sag between halves flags the row and keeps it — sustained performance is data. Vendor-split truth: nvidia-smi · rocm-smi · amdgpu hwmon; unavailable platforms declare so.

M7 Threads held, with the reason

Held fields state why −t doesn’t vary on GPU-bound chains, and where it remains a first- class axis instead.

N1/N2 Curves + verified limits

The depth axis v7 deferred for llama-server becomes a deliverable; M1’s arithmetic becomes a probed, margin-carrying verified number.

N5 Concurrency knee

Slots ladder with a defined knee — smallest slot count where TTFT p95 exceeds 2× its slots=1 value — derived from stored rows, never asserted.

N6/N7 Sustained policy + exchange

Steady-state discard and priced throttle re-runs, both recorded in config; export bundles that carry their own methods section and validate per row on import.

N3/N4 Live elsewhere

Multi-model quant comparisons gain blocking fairness checks on their own flow; perplexity/ KLD arrives as a labeled synthetic proxy — a footnote and a comparison column, never inside a ranking argmax until calibrated.

Boundary unchanged

Speed and memory always measured; quality only as a labeled proxy; estimates annotate and rank only where the goal asks; every policy is offered, none automatic.
